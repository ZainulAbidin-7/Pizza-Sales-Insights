🍕 Pizza Sales Insights Project
Welcome to the most "delicious" data project in my portfolio! This repository contains a full-scale analysis of a year's worth of pizza sales, designed to help a business owner understand their sales performance and customer preferences.

🚀 Project Overview
This project isn't just about counting crusts; it's about finding the "why" behind the numbers. I used SQL to perform the heavy-duty data processing and Power BI to create a dashboard that even a hungry customer could understand.

🛠️ Key Features & Insights

The KPI Scoreboard: Real-time tracking of Total Revenue, Average Order Value, and Total Orders.


Daily & Monthly Trends: Visualizing the peaks and valleys of sales to optimize staffing and inventory.


Sales by Category & Size: Breaking down revenue to see if customers prefer "The Big Meat" in Large or "The Hawaiian" in Medium.

Top & Bottom Performers: Identifying the best-sellers and the underdogs to help with menu engineering.

📂 What's Inside?

Pizza_Sales.csv: The raw dataset containing 48,620 rows of pizza goodness.

KPI and Chart Queries.sql: The "secret sauce"—SQL scripts used to calculate all business metrics.

Pizza_Sales_Insights.pbix: The interactive Power BI dashboard file.

🛠️ Tools Used
SQL Server: Data querying and KPI calculation.

Power BI: Data visualization and dashboarding.

MS Excel: Data cleaning and verification.
